Info & Tips

To add an RSS link to your header/navigation, include markdown like: [RSS](/u/{{ pathEscape .Data.User.Username }}/feed.xml) in the Header Markdown field.

Absolute URL: {{.Global.PublicURL}}/u/{{ pathEscape .Data.User.Username }}/feed.xml

The header markdown renders above all posts/pages.

Shortcodes you can embed in Header Markdown or any Post/Page body:

  • {posts} - list latest 10 posts.
  • {posts:5} - list latest 5 posts.
  • {posts:tag=tech} - list latest 10 posts tagged tech.
  • {posts:25:tag=go} - list latest 25 posts tagged go.
  • {archive} - full archive grouped by year (also available at /u/{{ pathEscape .Data.User.Username }}/archive).

Add an archive link manually, e.g. [Archive](/u/{{ pathEscape .Data.User.Username }}/archive).
